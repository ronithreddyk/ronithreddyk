## 🚀 Featured Project — PARACOSM

**[PARACOSM — Alternate Reality Simulator »](https://github.com/ronithreddyk/Paracosm)**

Ask one impossible question and PARACOSM builds an entire alternate world around it — a named reality, a cinematic narration, a causal timeline, your alternate self, and three AI-generated photographs from a life that never happened. It deliberately chases the *strange* answer, not the obvious one.

`Python` · `FastAPI` · `Google Gemini` · `Pollinations / Flux` · `JavaScript` · `REST`

> A full-stack generative-AI app with an async Python backend and a hand-built cinematic front-end. **[See the demo →](https://github.com/ronithreddyk/Paracosm)**
